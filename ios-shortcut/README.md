# iPhone: Immich Wallpaper Shortcut

Changes your iPhone wallpaper (lock screen, home screen, or both) to a random
photo from a shared Immich album, automatically on a schedule.

## Install (2 minutes)

1. Open the Shortcut link you were sent on your iPhone and tap **Add Shortcut**.
2. When it asks, paste the **Immich album link** you were sent
   (`https://…/share/…`).
3. Make sure your current wallpaper is a **Photos** wallpaper:
   Settings → Wallpaper → **Add New Wallpaper** → **Photos** → pick any
   photo → **Add** → **Set as Wallpaper Pair**.
4. Open **Shortcuts**, tap **Immich Wallpaper** once to test, and choose
   **Always Allow** when it asks to connect.

## Make it automatic

Shortcuts → **Automation** → **+** → **Time of Day** → pick a time, **Daily**
→ **Run Immediately** → choose **Immich Wallpaper** → **Done**.

Want it more often? Add more automations at other times.

## Change which screens it updates

Open Shortcuts → long-press **Immich Wallpaper** → **Edit** → at the last
action tap **Lock Screen and Home Screen** and pick what you want.
