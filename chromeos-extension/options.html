Wallpaper Rotator

This browser isn't running on ChromeOS. Settings will save, but Chrome only allows extensions to change the wallpaper on Chromebooks.

Chrome will ask permission to reach your photo server the first time.

Darkens photos so things on screen are easier to read. Applies right away.
